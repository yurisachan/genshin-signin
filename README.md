# ✨ Genshin Impact Auto Sign-in | 原神自动签到

基于 GitHub Actions 的轻量级自动化脚本，主要用于**原神国服（官服/B服）每日游戏自动签到**。

> ⚠️ **说明**：本项目包含米游社社区任务 (`bbs.py`) 代码，但目前处于**实验性阶段**，仅建议使用稳定的游戏签到功能 (`main.py`)。

## 🚀 功能特性

*   **稳定签到**：每日自动领取原石、经验书、摩拉等游戏内福利。
*   **多账号支持**：理论上支持多账号（需自行修改脚本循环逻辑）。
*   **消息推送**：支持 Server酱（微信/客户端）推送签到结果。
*   **零成本**：完全基于 GitHub Actions 免费运行，无需服务器。

## 🛠️ 快速开始 (Quick Start)

### 1. 🍴 Fork 本仓库
点击右上角的 **Fork** 按钮，将本项目克隆到你自己的 GitHub 账号下。

### 2. 🍪 获取 Cookie
游戏签到只需要**网页版 Cookie**，获取非常简单：

1. 电脑浏览器打开 [米哈游通行证](https://user.mihoyo.com/) 并登录。
2. 按 `F12` 打开开发者工具，点击 **Console (控制台)**。
3. 输入 `document.cookie` 并回车。
4. 复制打印出来的整段字符串（包含 `ltoken` 和 `ltuid` 即可）。

### 3. 🔑 配置环境变量 (Secrets)
进入你 Fork 后的仓库，依次点击：
`Settings` -> `Secrets and variables` -> `Actions` -> `New repository secret`

添加以下变量：

| 变量名 (Name) | 必填 | 说明 |
| :--- | :---: | :--- |
| **GS_COOKIE** | ✅ | **核心凭证**。填入上一步获取的 Cookie 字符串。 |
| **SEND_KEY** | ❌ | (可选) Server酱的 SendKey，用于接收推送通知。 |

### 4. ▶️ 启用并测试
1. 点击仓库顶部的 **Actions** 栏。
2. 点击左侧的 **Genshin Impact Signin** 工作流。
3. 点击右侧的 **Run workflow** 按钮手动触发一次。
4. 等待几秒后刷新，查看运行日志。如果显示 `✅ 签到成功`，则部署完成。

## ⏰ 自动运行机制

*   脚本默认配置为 **每天北京时间 09:15** 左右自动运行。
*   你可以在 `.github/workflows` 文件夹中修改定时策略。

## ⚙️ 常见问题

**Q: 运行显示 `login_ticket` 失效或获取角色失败？**
A: 请确保 Cookie 中包含 `ltoken` (或 `cookie_token`) 和 `ltuid` (或 `account_id`)。建议重新在无痕模式下登录并提取 Cookie。

**Q: 支持国际服吗？**
A: 目前脚本逻辑主要针对国服 (`hk4e_cn`)，国际服接口不同，暂不支持。

**Q: 这个脚本会封号吗？**
A: 该脚本仅模拟正常的网页签到请求，不涉及游戏内数据修改，理论上风险极低。但为了安全起见，建议仅用于小号或自行评估风险。
